# Room OS roadmap

The roadmap describes direction, not guaranteed delivery dates.

## v0.1 — Public foundation

- [x] Modular event-driven architecture.
- [x] Camera, hand tracking and gesture recognition.
- [x] Guided gesture and virtual-mouse calibration.
- [x] Local presence and face recognition.
- [x] Extensible Windows action registry.
- [x] Optional Gemini visual analysis.
- [x] Tests, security boundaries and Windows package.

## v0.2 — Reliability and accessibility

- [ ] Hardware diagnostics and camera capability report.
- [ ] Import and export of non-biometric settings.
- [ ] Better keyboard and screen-reader navigation.
- [ ] In-app privacy dashboard for local and cloud processing.
- [ ] Additional calibration quality metrics.

## v0.3 — Extensibility

- [ ] Versioned module API and lifecycle contract.
- [ ] User-created action packs with explicit permissions.
- [ ] Action and gesture profile sharing without biometric data.
- [ ] Localization infrastructure.

## Ideas under evaluation

- Multiple camera profiles.
- Optional offline visual-language providers.
- Signed Windows installer and automatic updates.
- Performance telemetry that is local and opt-in only.

Suggestions are welcome through
[GitHub Issues](https://github.com/diegomoren-lgtm/room-os/issues).
