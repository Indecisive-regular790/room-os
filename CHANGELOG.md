# Changelog

All notable public changes to Room OS are documented here.

## [0.1.0] - 2026-08-03

### Added

- PySide6 desktop interface and first-run configuration wizard.
- Modular camera, hand, gesture, virtual mouse and presence processing.
- Local face registration and recognition.
- Extensible action engine with allowlisted Windows integrations.
- Optional Gemini visual intelligence with environment-only credentials.
- Rate limiting, input validation, log redaction and rich-text escaping.
- Windows build and installation scripts.
- 131 automated tests.

### Privacy

- Local profiles, face images, embeddings, calibrations and logs are excluded
  from version control and release packages.
